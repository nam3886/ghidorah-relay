# Error codes

Generated by `python -m relay_core.errors`; do not edit. Source: `packages/relay-core/src/relay_core/errors.py`.

Body: `{"error": {"code", "message", "type", "param"}}`. A job's refund state is the `refunded` field of its status, not part of the error.

The internal reference: a client never sees these codes nor their messages. It sees the **Public** code instead: a request-time code of a client domain as itself, any other as one of the neutral codes below, with the code's own customer sentence (not listed here) or the neutral one.

| Public code | Sending again helps | Sentence |
|---|---|---|
| `content_refused` | No: change the prompt or the images first. | The provider refused to make this. Sending the same request again will not help; change the prompt or the images. |
| `generation_failed` | It may. | The generation failed and nothing was delivered. Sending the request again may work. |
| `temporarily_unavailable` | Later. | There is no capacity for this request right now. Sending the request again later may work. |
| `timeout` | It may. | The result did not arrive in time. Sending the request again may work. |
| `invalid_input` | No: change the input first. | An input of the request could not be used. Sending the same request again will not help; change the input. |
| `internal_error` | It may. | An error on our side ended the request. Sending the request again may work. |
